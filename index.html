MMV Voice

Local-first. Whisper transcription → on-device Gemma punctuation → a deterministic check that rejects any change to words or numbers. Audio, text and models stay on your machine; nothing is sent anywhere unless you opt in. Linux desktop GUI, AGPL-3.0, no fine-tuning.

Source on GitHub README Measured status (2026-09-25) Earlier trial on HOLD (2026-09-24)

What it does

  • Runs entirely on your own computer by default: local Whisper, local Ollama model, loopback-only endpoint, no accounts, no telemetry.
  • Transcribes with Whisper large-v3-turbo, language auto-detected.
  • Asks a local gemma4:12b-it-qat (Ollama, through the MMV harness) to insert punctuation and line breaks only.
  • Rejects every candidate whose words or numbers differ from the transcript and keeps the raw text for that chunk; the report shows source, candidate and reason.
  • Checks the Ollama model digest before the first call; a different build is not used silently.
  • Optional, off by default: speaker attribution, an LLM fidelity pass, minutes, secretary digest export. An opt-in cloud engine exists and asks before sending anything off-machine.

What it is not

It does not correct transcription errors — a candidate that fixes a misheard word is rejected because the words changed. Punctuation can still alter meaning; the check does not prove semantic fidelity. Languages other than Japanese and English are unevaluated.

Run it

Linux, Python 3.10, PyTorch with CUDA, ffmpeg, Ollama with gemma4:12b-it-qat, and the MMV harness. Setup steps, configuration and troubleshooting are in the README.
